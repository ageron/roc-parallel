# Bundled runtime notices

Release archives include Zig 0.16.0 compiler support and target runtime inputs built by Zig. These notices are copied from that Zig distribution:

- `zig.txt`: Zig and compiler support licensing.
- `musl.txt`: static Linux C runtime licensing.
- `mingw.txt`: Windows MinGW/UCRT support licensing.

When upgrading Zig, refresh these notices from the new distribution.
